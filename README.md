### 功能概览

- 多服务器独立页面、连接历史、公钥或密码登录、连接状态及失败原因。
- CPU 架构、GPU/NPU 信息、内存和挂载磁盘；查询所有已连接服务器的卡占用情况。
- 运行任务、父子关系、Docker 容器，按名称、时间等排序；结束任务受权限和只读设置限制。
- 本地/远程双栏文件浏览、多选上传下载、拖拽、搜索和常用文件操作。
- 本机与服务器、服务器之间目录映射，可选覆盖；支持直传和用户选择目录的本机中转。
- 黑、蓝、白主题，字号和快捷键设置，内置离线帮助。

### 运行条件与数据存储

客户端面向 Windows；远程服务器需要 SSH/SFTP 与 Python 3，相关监控功能需要服务器安装对应驱动工具（`nvidia-smi` 或 `npu-smi`），Docker 信息需要 Docker 及访问权限。

首次启动不附带服务器。用户自行添加连接；连接历史保存在本机 `%APPDATA%\ServerLook`，保存的密码由 Windows DPAPI 保护，不上传 GitHub。测试中的示例域名、回环地址、账户名和测试口令仅用于模拟或本地测试，不是实际服务器凭据。

当前为私有仓库，访问源码和 Release 下载需要登录已获授权的 GitHub 账号；仓库所有者可在 Settings 中修改可见性。源码包不包含本机配置、截图、日志、密钥或原工作区的 Git 历史。

## 下载与快速启动

- 便携版：本地构建的 `服务器看看-2.14.2.exe` 可双击运行，无需安装 Python；当前 Release 提供源码包，EXE 在线附件暂不可用。
- 源码用户：下载并解压源码 ZIP，安装带 Tcl/Tk 的 Python 3.12 并勾选加入 PATH，双击 `install.cmd` 安装依赖，再双击 `start.cmd` 启动。首次安装需要网络，依赖放在项目内的 `.venv`。
- PowerShell 安装并启动：`powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Launch`。执行策略仅对本次进程生效。
- EXE 和已安装依赖的源码版均可离线启动；连接服务器需要网络可达。源码安装完成后移动项目目录，建议删除 `.venv` 并重新安装。
- 构建 EXE：安装依赖后，执行 `.\.venv\Scripts\python.exe -m pip install pyinstaller==6.22.0`，然后在当前 PowerShell 中执行 `$env:Path = "$PWD\.venv\Scripts;$env:Path"` 和 `.\build_client.ps1`，产物在 `dist`。

发布仅包含源码、文档、资源和脚本，不包含连接历史、密码、本机虚拟环境或构建缓存。源码安装脚本不会自动安装 Python，也不修改全局 Python 依赖。

## 2.4 多选传输与直接拖拽

运行 `dist/服务器看看-2.10.0.exe`，已包含 Python、认证依赖和原生拖拽组件。

- 选中一个或多个服务器文件/文件夹，按住左键直接拖到右侧本地列表或 Windows 文件资源管理器。无需“准备拖拽”按钮。拖到 App 本地文件夹行会复制到该文件夹，拖到空白处或文件行则复制到当前目录。
- 拖到 Windows 资源管理器时，首次拖拽需将文件下载到临时目录，期间显示等待窗口，可取消。若等待时松开鼠标，完成后重新拖动即可，复用已下载文件。大文件需要等待实际下载。
- 拖拽始终复制，保留服务器源文件。App 内复制会确认覆盖/合并，拖到资源管理器由 Windows 处理同名冲突。取消或失败可能留下部分目标文件；批量遇错停止，已完成的项保留。
- 临时目录为 `%TEMP%\server-look-drag-*`，需要足够空间。为避免 Windows 仍在复制时源文件被删除，关闭 App 不立即清理；确认完成后可手动删除。缓存仅在本次 App 会话中复用，重新连接或源文件元数据变化后重新下载。
- Windows 不支持的名称不能下载；密码模式额外拒绝目录中的大小写重名项、符号链接。App 和资源管理器权限级别不同可能阻止跨窗口拖拽。

验证包括原生组件加载、拖拽回调、多项本地复制及本地 SSH/SFTP 集成测试；实际鼠标拖到资源管理器仍需手动验收。

## 2.2 文件管理

文件浏览为双栏界面：左侧服务器目录树和文件列表，右侧本地文件列表。本地地址栏支持输入盘符和路径；双击本地文件夹在客户端内浏览选中的文件夹；点击“打开窗口”才使用 Windows 文件资源管理器打开选中的文件夹，未选中时打开当前目录。两侧均提供新建文件夹。

选择本地项后点击“上传到服务器”，传入左侧当前服务器目录；选择服务器项后点击“下载到本地”，保存到右侧当前本地目录。支持多选文件或递归文件夹。每次传输先显示服务器、来源及目标目录并确认；同名文件覆盖，目录合并。只读模式禁止上传及服务器新建目录，仍可下载。传输期间有动态进度条（表示正在执行，不显示字节百分比），可取消；取消、断线或失败可能留下部分目标文件，不支持断点续传或回滚。关闭页面会取消其传输。

上传下载后台使用系统 OpenSSH 的 SFTP 客户端，服务器需启用 SFTP 子系统；不安装额外服务。传输使用独立连接，不占用目录浏览长连接。新建服务器目录也复用目录连接。右侧本地目录读取使用 Windows 文件系统；首次访问慢速网络映射盘可能需要等待。

## 2.0 新增功能

- **硬件配置**：CPU 架构、型号、逻辑核数、插槽与线程信息、操作系统、内存、NPU 型号及健康状态；详细实时指标见“NPU 状态”。
- **磁盘与挂载**：展示本机磁盘及 NFS 等挂载的容量、已用、可用和使用率，高使用率着色提示；双击挂载进入文件浏览。
- **文件浏览**：左侧按需展开目录树，右侧双击进入目录，支持地址栏、上级目录、隐藏文件和符号链接。2.2 起支持新建文件夹与双向传输。
- **快速目录切换**：首次浏览建立独立 SSH 长连接，后续目录读取复用同一连接和远程 Python 进程，不逐目录登录。每服务器缓存最多 32 个目录，15 秒内返回缓存；“前往 / 刷新”强制读取最新内容。监控采集与目录读取并行，快速连续点击优先处理最新目录。

目录按单层读取，不递归统计文件夹大小；单次最多展示 3000 项并提示截断。文件夹大小显示为“—”。网络延迟、远程磁盘/NFS 响应和目录规模会影响首次读取；断线后重试可重建目录连接。目录缓存与长连接在断开服务器时清理。挂载统计排除虚拟文件系统，绑定挂载可能指向同一设备，不能直接将各行容量相加。

面向昇腾 Linux 宿主机，无第三方 Python 依赖。依赖现有 `npu-smi`、`docker` 和 Python 3.9+；结束进程需要 Linux pidfd 支持。建议在宿主机以 root 运行，才能看到完整进程及 Docker 信息。

## 按键

| 按键 | 功能 |
| --- | --- |
| ↑ / ↓ | 选择进程或容器；详情中滚动 |
| Tab | 在 NPU 任务与运行中的 Docker 容器之间切换 |
| a | 切换显示所有运行容器内的进程，包括未占用 NPU 的启动器 |
| Enter | 打开/关闭详情；详情页面暂停自动刷新以便阅读 |
| p | 选择上一级进程，可逐级定位 torchrun、服务启动器等父任务 |
| k | **立即**向选中进程及当前子进程发送 SIGTERM |
| K（Shift+k） | **立即**向选中进程及当前子进程发送 SIGKILL |
| s，然后 3 秒内再次 s | 停止选中容器，或选中任务所属容器；先等待 10 秒优雅退出 |
| r | 退出详情并刷新 |
| q / Ctrl+C | 退出工具 |

NPU 表显示卡/芯片、利用率、温度、功耗、HBM，以及占用设备的 PID、用户名、显存、任务启动时间和所属容器。同一 PID 使用多张卡时合并显示。Enter 查看完整启动命令、工作目录、父进程链、容器镜像、容器创建和启动时间、入口命令、重启策略及挂载目录。时间包含时区；任务启动时间来自 `/proc`，不同于容器启动时间。

界面使用 ANSI 终端与 Python 标准库，不依赖 curses。默认在每次采集完成 2 秒后启动下一次后台采集；本机完整采集约需 2.5 秒，采集期间仍可操作按键。选中进程退出后不会自动改选其他任务，需用方向键重新选择。

默认只列出 `npu-smi` 实际报告的 NPU 进程。没有 NPU 任务时，可以用 Tab 查看容器或 a 查看容器内其他进程。容器归属优先使用 cgroup，并通过父进程链补充判断。

`k/K` 不杀整个进程组，不自动停止 Docker，也不自动向上扩大结束范围。若任务由父启动器重拉起，应先用 p 定位父任务再结束，或用 s 停止其整个容器。结束前会核对 PID 的启动标识并通过 pidfd 发送信号；PID 1、工具自身及其祖先进程受保护。进程树是操作瞬间的快照，操作后新创建或已脱离父子关系的进程可能继续运行。停止容器会影响其中全部任务。

容器入口命令来自 Docker 当前配置，无法还原历史上输入的完整 `docker run` 原始命令。完整启动命令可能包含用户自行传入的令牌等参数，分享输出前请检查。工具不读取环境变量或保存监控日志。

## Windows 桌面客户端

双击 `dist/服务器看看-2.10.0.exe`，启动显示一个空白“新服务器”页面，不内置服务器地址。填写地址后连接；“＋ 添加服务器”可增加页面，再用“连接全部页面”或逐页连接。各页独立刷新，切换页面不会断开连接。默认用户 root、端口 22，可选择公钥或账号密码认证。EXE 已包含 Python、Tk、Paramiko 和拖拽组件；公钥模式还需系统 OpenSSH。新电脑需自行配置公钥或填写密码并核验服务器主机密钥，私钥和密码不会打包进软件。

“运行任务”显示开始时间、PID、NPU 显存、关联 Docker 和命令；1.2 版默认显示容器内全部进程，取消勾选“显示容器内全部进程”后仅显示 NPU 任务。顶部统计 NPU 任务、容器及进程数量，NPU 空闲时明确提示。“Docker 容器”显示容器开始时间、镜像和入口 PID，选中后查看完整配置。“NPU 状态”显示 npu-smi 实际输出。后台 SSH 采集，约每 3 秒尝试刷新，采集中不重复发起请求。

选中任务后，Delete 发送 SIGTERM，Shift+Delete 发送 SIGKILL，均作用于当前任务及其子进程，操作前显示确认框。“选中父任务”可定位启动器；“停止选中 Docker”停止该容器及其中全部任务。任务身份同时核验 PID 和启动标识；数据读取失败、采集中、只读模式或原任务消失时禁用结束操作。不会自动改选其他任务。时间使用服务器时区。

1.1 版通过 SSH 将随软件携带的采集代码传到服务器内存执行，无需预装 `/root/npu-top/npu_top.py`，不写入服务器文件、不启动额外服务、不开放监控端口。服务器需有 Python 3.9+ 和 npu-smi，查看容器还需 Docker 及对应权限。当前默认以 root 连接，操作权限与 SSH 用户相同。界面内可能显示启动参数中的敏感信息，请谨慎分享。

源码启动可用 `启动客户端.cmd`（需要本机 Python/Tk）。重新打包：先把 `pyinstaller==6.22.0` 安装至 `.build-deps`，再运行 `build_client.ps1`。桌面测试执行 `python -m unittest test_client -v`；单台服务器只读验证执行 `python smoke_client.py`，双服务器同时连接验证执行 `python smoke_multiserver.py`。

## 2.3.0 密码登录与 NVIDIA GPU

- 认证方式可选择“公钥登录”或“账号密码”。密码框掩码显示，连接后清空输入；勾选“记住密码”时，连接成功后使用 Windows DPAPI 加密保存，详见下方连接历史说明。
- 密码模式的监控、目录浏览、新建目录和双向传输共用 Paramiko SSH 连接。公钥模式保留 Windows OpenSSH。服务器必须允许该用户使用密码认证。
- 两种模式均检查主机密钥。首次连接请先在终端执行 `ssh 用户@服务器`（自定义端口加 `-p 端口`），核对指纹后信任，再打开 App 连接；不自动忽略主机密钥变化。
- 自动采集昇腾 `npu-smi` 和 NVIDIA `nvidia-smi`，允许混合设备。硬件配置页增加 GPU 型号、数量、UUID、驱动和显存容量；“NPU / GPU 状态”显示利用率、显存、温度和功耗。CPU、内存及挂载磁盘继续采集。
- NVIDIA 任务使用计算进程查询，支持同一 PID 占用多卡；不包含仅图形渲染的进程。驱动不支持的指标保留 N/A，MIG 使用返回的 UUID 区分。远端目前仍需 Linux、python3 和相应厂商驱动命令。
- 新 EXE 内置密码登录依赖，直接运行即可。源码运行需先 `python -m pip install -r requirements.txt`。
- 密码模式递归传输普通文件/文件夹，拒绝符号链接；覆盖/合并与取消残留文件行为同前版。


### 2.3.1

移除内置服务器地址。启动仅显示空白的“新服务器”页面，填写地址后连接；可通过“添加服务器”继续新增页面。


### 2.3.2

账号密码模式首次连接未知服务器时，在客户端弹窗显示 SHA256 主机指纹，核对并确认后继续；信任记录保存在当前 Windows 用户的 ~/.ssh/server_look_known_hosts。已知服务器密钥变化时阻止连接。区分密码认证失败、主机密钥变化及其他 SSH 握手失败。公钥模式仍使用系统 OpenSSH 的 known_hosts。

### 本地拖拽上传（2.4.2）

可在右侧本地列表 Ctrl / Shift 多选文件或文件夹，直接拖到左侧服务器列表；也支持从 Windows 文件资源管理器拖入。拖到目录行上传到该目录，拖到文件行或空白处上传到当前服务器目录。确认目标后开始后台上传，可使用取消传输按钮；同名文件覆盖、文件夹合并。只读模式禁止上传。拖拽为复制，本地原文件保留。

### 删除文件和文件夹（2.4.2）

本地和服务器文件列表均支持多选后点击删除按钮、按 Delete 键或右键选择删除。右键已选中项保留多选，右键其他项只选择该项。确认框列出全部路径、数量及服务器地址；删除是永久删除，不进入回收站，文件夹递归删除。仅允许删除当前目录的直接子项，符号链接只删除链接本身。远程只读模式是当前服务器页的软件保护开关，开启时禁止所有远程删除、上传和新建目录；关闭后仍受服务器账号权限限制。删除在后台执行，当前操作完成前禁止并发文件操作；删除不可撤销，不提供取消按钮，中途失败可能已经删除部分目标。

## 2.5 文件操作与精简交互

- 本地、服务器文件列表双击文件夹进入；顶部保留上级、刷新、本地打开窗口。右键文件或空白区域打开操作菜单：新建文件夹、拷贝、粘贴、重命名、压缩、解压、删除。空白区域右键会清除选择。
- Ctrl+C 拷贝选中项，进入目标目录后 Ctrl+V 粘贴；F2 重命名单项，Delete 永久删除并确认。可多选复制、压缩、删除。
- 剪贴板在本页会话内有效，仅支持同一本地电脑或同一服务器内粘贴；重新连接后需要重新拷贝。跨本地和服务器仍使用拖拽、上传、下载。
- 压缩生成 ZIP（支持大文件 ZIP64）；解压支持 ZIP、TAR、TAR.GZ/TGZ、TAR.BZ2、TAR.XZ，需输入一个尚不存在的目标文件夹。暂不支持 RAR、7Z 和加密压缩包。
- 复制、重命名、压缩、解压拒绝覆盖已有目标。不能复制到自身或子目录。复制及归档遇到符号链接、目录联接、特殊文件会拒绝；解压校验成员路径，拒绝越界路径和链接，在临时新目录完成后交付。
- 只读模式允许浏览和拷贝选择，禁止服务器粘贴、新建、重命名、压缩、解压、删除。本地写操作不受服务器只读模式影响。
- 操作在后台执行并显示忙状态；非传输操作暂不支持取消或百分比进度。大文件远程复制、压缩、解压复用 SSH 通道，最长等待 24 小时；断开连接可能中断操作。复制遇到磁盘不足等错误可能留下已复制项，请检查后重试；不自动回滚。

## 2.12.0 多端目录映射与本机中转

打开“映射”，默认只有一个本机目录。点击“添加服务器”，从已连接服务器中按地址选择并浏览远程目录；可添加多个服务器或本机目录。选中目录后点击“设为来源”，其余目录通过“切换目标”设置为一个或多个目标；双击目录修改路径。

“本机中转目录”右侧点击“选择文件夹…”即可选择任意有写入权限、空间足够的本机磁盘目录，保存配置后会记住此地址。支持本机→服务器、服务器→本机、服务器→服务器。默认递归补齐缺少的文件；勾选覆盖后替换同路径文件，保留目标独有文件。映射不删除目标文件，也不跟随符号链接。

服务器间勾选“优先直传”时，源服务器使用自己的 SSH 信任和免密认证连接目标服务器，两端需有 Python 3 与 SSH；本机密码和私钥不会上传。连接失败，或连续 15 秒低于设定阈值（默认 1 MB/s）时，自动使用所选本机目录中转。取消勾选可直接使用本机中转。中转逐块读取、发送和清理，每块最多 8 MiB，不会先下载整个目录或整个大文件；需额外保留约 16 MiB 空闲空间。异常或取消会清理本次临时文件，目标原文件在传输成功前保留。目标服务器只读时禁止映射写入。

选中文件右键“映射”仅传选中项，配置来源需与选中项所在位置一致。旧版两端映射配置会自动转换为一个来源、一个目标。

搜索目录支持可视化选择：在搜索窗口选择“本地”或“当前服务器”，点击路径右侧“选择文件夹…”。本机使用系统文件夹选择窗口，远程复用 RemoteDirectoryDialog 和现有 SSH 目录通道，选定后回填搜索起始路径。

搜索目标下拉框支持本地和所有已打开的服务器页面（按账号、地址、端口区分）；选择服务器后，可可视化选择该服务器上的搜索目录。未连接的页面需先连接。双击结果会定位到搜索时所选服务器；页面关闭或连接变更后需重新搜索。

2.12.1：双击搜索结果切换到对应服务器文件浏览。文件夹进入该目录；文件进入所在目录并在目录加载后选中。搜索窗口暂时隐藏，点击搜索入口可恢复结果。映射配置的“参与目录数”表示配置中的目录位置数量，不是其内部文件或子目录数量。

2.12.2：映射入口简化为历史目录映射下拉框、新增映射和修改映射。仅新增或修改时展开编辑区，保存后自动收起；选择历史方案后可直接一键映射。

产品代码集中在 `server_look/`，按应用、界面、连接、文件、映射、翻译、远程采集和配置分层；`tests/`、`tools/`、`docs/` 分别存放测试、开发工具和文档。维护入口和验证命令见 [开发说明](docs/DEVELOPMENT.md)。
